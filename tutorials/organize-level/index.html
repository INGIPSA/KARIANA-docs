    Tutorial: Organize Your Level#

    Learn to keep your levels clean and navigable with proper organization.

    What You'll Learn#

    • Creating folder structures
    • Organizing actors by type
    • Naming conventions
    • Using auto-organization

    Prerequisites#

    • A level with multiple actors
    • Completed previous tutorials (or have a messy level to organize)

    Step 1: View Current State#

    First, see what you have:

    "List all actors in the level"

    Or:

    "Show the current World Outliner hierarchy"

    Step 2: Create Basic Folders#

    Set up a folder structure:

    "Create folders: Environment, Lighting, Gameplay"

    Step 3: Organize by Type#

    Move actors to appropriate folders:

    "Move all static meshes to the Environment folder"
"Move all lights to the Lighting folder"
"Move all triggers to Gameplay"

    Step 4: Create Subfolders#

    Add more organization:

    "Create subfolder 'Props' inside Environment"
"Create subfolder 'Architecture' inside Environment"
"Create subfolders 'Key', 'Fill', 'Ambient' inside Lighting"

    Step 5: Rename Actors#

    Apply consistent naming:

    "Rename all point lights to 'PointLight_##' with sequential numbers"
"Rename all cubes with prefix 'SM_Cube_'"

    Step 6: Auto-Organization#

    Let KARIANA organize automatically:

    "Auto-organize all actors by type"

    This creates a structure like: 

    Level
├── Static Meshes
│   ├── Cubes
│   ├── Spheres
│   └── Others
├── Lights
│   ├── Point Lights
│   ├── Spot Lights
│   └── Directional Lights
└── Cameras

    Step 7: Tag Important Actors#

    Add tags for quick finding:

    "Tag all interactive objects with 'Interactive'"
"Tag the main light as 'KeyLight'"

    Find them later:

    "Select all actors tagged 'Interactive'"

    Step 8: Clean Up#

    Remove clutter:

    "Remove all empty folders"
"Delete actors named 'Untitled' or 'Default'"

    Organization Templates#

    By Function#

    "Create organization structure:
- Gameplay
  - PlayerStart
  - Spawners
  - Triggers
  - Interactables
- Environment
  - Architecture
  - Props
  - Vegetation
- Lighting
  - Key Lights
  - Fill Lights
  - Ambient
- VFX
- Audio"

    By Area#

    "Create area-based organization:
- Area_Entrance
- Area_MainHall
- Area_Corridor
- Area_Exit
Each with Meshes, Lights, Gameplay subfolders"

    Naming Convention Reference#

    Type Prefix Example
    Static Mesh SM_ SM_Chair_01
    Blueprint BP_ BP_Door_Main
    Material M_ M_Wood_Oak
    Light L_ L_Point_01
    Trigger T_ T_Entrance

    Step 9: Verify Organization#

    Check your work:

    "Show the complete folder hierarchy"
"List any actors not in folders"
"Find duplicate named actors"

    Maintaining Organization#

    As You Work#

    "Spawn a cube in the Environment/Props folder"
"Create light in Lighting/Fill"

    Regular Cleanup#

    "Move any unfiled actors to appropriate folders"
"Clean up empty folders"
"Check for naming convention violations"

    Challenge: Organize a Messy Level#

    Start with this messy setup:

    "Spawn 10 random cubes at random positions"
"Spawn 5 point lights at random positions"
"Spawn 3 spotlights at random positions"
"Spawn 2 cameras at random positions"

    Now organize it properly!

    Solution 
    "Organize the level:

Create folder structure:
- Environment/Props
- Lighting/Points
- Lighting/Spots
- Cameras

Move actors:
- All cubes to Environment/Props
- All point lights to Lighting/Points
- All spotlights to Lighting/Spots
- All cameras to Cameras

Rename:
- Cubes to 'Prop_Cube_##'
- Point lights to 'L_Point_##'
- Spotlights to 'L_Spot_##'
- Cameras to 'Cam_##'"
