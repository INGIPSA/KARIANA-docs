    Tutorial: Create Materials#

    Learn to create and apply materials to bring your scenes to life.

    What You'll Learn#

    • Creating colored materials
    • Setting material properties
    • Applying materials to actors
    • Material recipes for common looks

    Prerequisites#

    • Completed Spawn Your First Actor tutorial
    • Some actors in your level to apply materials to

    Step 1: Create a Simple Color Material#

    Start with a basic red material:

    "Create a red material called M_Red"

    This creates a material with red base color.

    Step 2: Apply the Material#

    Apply it to an actor:

    "Spawn a cube at 0, 0, 100"
"Apply M_Red to the cube"

    The cube should now be red!

    Step 3: Create with Properties#

    Let's make a more interesting material:

    "Create a material called M_Gold with:
- Base color: gold (255, 200, 50)
- Metallic: 1.0
- Roughness: 0.2"

    Apply it:

    "Spawn a sphere at 200, 0, 100"
"Apply M_Gold to the sphere"

    Step 4: Material Property Guide#

    Property Range Effect
    Metallic 0-1 0=plastic, 1=metal
    Roughness 0-1 0=mirror, 1=matte
    Specular 0-1 Highlight brightness

    Try These Combinations#

    Shiny Plastic: 

    "Create M_ShinyPlastic: blue color, metallic 0, roughness 0.1"

    Brushed Metal: 

    "Create M_BrushedMetal: silver color, metallic 1, roughness 0.4"

    Matte Rubber: 

    "Create M_Rubber: black color, metallic 0, roughness 0.9"

    Step 5: Emissive Materials#

    Create glowing materials:

    "Create a material called M_Glow with:
- Base color: cyan
- Emissive color: cyan
- Emissive intensity: 5"

    This material will appear to glow!

    Step 6: Transparent Materials#

    Create glass-like materials:

    "Create a material called M_Glass with:
- Base color: light blue
- Opacity: 0.3
- Blend mode: translucent"

    Note

    Transparent materials require the blend mode to be set to translucent.

    Step 7: Material Showcase#

    Create a showcase of different materials:

    "Spawn 5 spheres in a row at Y=0, Z=100, from X=-400 to X=400"

    Then apply different materials:

    "Apply M_Red to the first sphere"
"Apply M_Gold to the second sphere"
"Apply M_ShinyPlastic to the third sphere"
"Apply M_BrushedMetal to the fourth sphere"
"Apply M_Glow to the fifth sphere"

    Step 8: Quick Material Application#

    Apply materials directly without creating first:

    "Make the cube blue"
"Give the sphere a gold metallic look"
"Make the cylinder look like chrome"

    KARIANA will create and apply the material automatically.

    Material Recipes#

    Chrome#

    "Create M_Chrome: silver color, metallic 1, roughness 0.05"

    Copper#

    "Create M_Copper: RGB(184,115,51), metallic 1, roughness 0.3"

    Plastic (Colored)#

    "Create M_PlasticRed: red color, metallic 0, roughness 0.5"

    Wood-like#

    "Create M_Wood: RGB(139,90,43), metallic 0, roughness 0.8"

    Neon#

    "Create M_Neon: pink color, emissive pink at intensity 10"

    Challenge: Material Gallery#

    Create a gallery showcasing 6 different material types:

    1. Matte plastic
    2. Glossy plastic
    3. Brushed metal
    4. Polished metal
    5. Emissive/glowing
    6. Transparent
    Solution 
    "Create material gallery:

Spawn 6 spheres in a 2x3 grid at Z=100, spacing 300 units

Create and apply:
- M_MattePlastic (red, metallic 0, roughness 0.8) to sphere 1
- M_GlossyPlastic (blue, metallic 0, roughness 0.1) to sphere 2
- M_BrushedMetal (silver, metallic 1, roughness 0.5) to sphere 3
- M_PolishedMetal (gold, metallic 1, roughness 0.05) to sphere 4
- M_NeonGlow (cyan, emissive cyan intensity 5) to sphere 5
- M_Glass (white, opacity 0.2, translucent) to sphere 6"
