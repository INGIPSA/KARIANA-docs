    KARIANA#

    AI-Powered Unreal Engine Control

    Control Unreal Engine with natural language through 218+ MCP tools. Build, organize, and automate your game development workflow with Claude.

    Get Started View on GitHub

    Overview#

    KARIANA is an AI-powered Unreal Engine 5.7+ plugin that enables comprehensive engine control through the Model Context Protocol (MCP). Describe what you want in natural language, and Claude executes it in Unreal Engine.

    Example

    You: "Spawn a red cube at position 100, 0, 50 and add a point light above it"

    Claude: Spawns the cube, creates a red material, applies it, and positions a point light - all automatically.

    Key Features#

    218+ MCP Tools#

    Complete programmatic control of Unreal Engine with tools for actors, materials, blueprints, PCG, and more.

    Action Recorder#

    Record your editor actions and generate reusable skills that can be replayed automatically.

    22 Custom PCG Nodes#

    Advanced procedural content generation with noise functions, patterns, and point manipulation.

    LLM Integration#

    Built-in support for Claude, OpenAI, DeepSeek, and XAI for AI-powered workflows.

    KARIANA-Anim#

    Tweening system for smooth animations and runtime motion control.

    Spatial Patterns#

    Grid, circular, spline, scatter, and surface-based spawning with expert pattern selection.

    Quick Start#

    irm kariana.ai/install.ps1 | iex
    1. Download from GitHub Releases
    2. Extract to your UE Plugins folder
    3. Enable in Edit > Plugins
    4. Configure Claude Desktop

    Architecture#

    graph LR
    A[You] -->|Natural Language| B[Claude]
    B -->|MCP Tools| C[KARIANA]
    C -->|Commands| D[Unreal Engine]
    D -->|Results| C
    C -->|Response| B
    B -->|Confirmation| A

    Tool Categories#

    Category Tools Description
    Actor Management 40+ Spawn, transform, physics, selection
    Blueprint 25+ Create, edit, compile, node connections
    Materials 15+ Create, edit, apply materials
    Lighting 10+ Lights, shadows, build lighting
    Camera 10+ Camera rigs, cinematics, screenshots
    Organization 10+ World Outliner, asset management
    Navigation 3 NavMesh, pathfinding
    Patterns 5 Grid, circular, scatter, spline, surface
    Streaming 4 Level streaming, World Partition
    Foliage 4 Paint, remove, create foliage types
    Spatial 3 Radius queries, overlap detection
    Animation 15+ Tweening, sequencer, montages
    PCG 22 Custom procedural generation nodes

    Requirements#

    • Unreal Engine 5.7+
    • Claude Desktop or compatible MCP client
    • Windows, macOS, or Linux
