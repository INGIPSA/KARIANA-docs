    Frequently Asked Questions#

    Common questions about KARIANA.

    General#

    What is KARIANA?#

    KARIANA is an AI-powered plugin that connects Claude (or other AI assistants) to Unreal Engine, allowing natural language control of the engine. Instead of clicking through menus, you describe what you want and it happens.

    What can I do with KARIANA?#

    • Spawn and manipulate actors
    • Create and apply materials
    • Set up lighting
    • Create Blueprints
    • Organize your level
    • Take screenshots
    • And 200+ more operations

    Which Unreal Engine versions are supported?#

    KARIANA requires Unreal Engine 5.7 or newer.

    Which AI assistants work with KARIANA?#

    Currently, Claude Desktop is the primary supported client. Any MCP-compatible client should work.

    Is KARIANA free?#

    Yes, KARIANA is open source and free to use.

    Installation#

    Where do I install the plugin?#

    Two options:

    1. Engine-wide: [UE Install]/Engine/Plugins/Marketplace/KARIANA/
    2. Per-project: [Your Project]/Plugins/KARIANA/

    The installer failed. What do I do?#

    Try manual installation:

    1. Download from GitHub Releases
    2. Extract to your plugins folder
    3. Enable in Edit > Plugins
    4. Configure Claude Desktop manually

    See Installation Guide for details.

    Do I need to install anything else?#

    Yes, enable these UE plugins:

    • Remote Control API
    • Remote Control Web Interface
    • Python Script Plugin

    Usage#

    How do I talk to Unreal Engine?#

    Just describe what you want in natural language:

    "Spawn a red cube at 0, 0, 100"
"Add a spotlight above the cube"
"Take a screenshot"

    Do I need to know tool names?#

    No! Just describe your intent. KARIANA figures out which tools to use.

    Can I undo KARIANA's changes?#

    Yes, use Unreal Engine's standard undo (Ctrl+Z). Most KARIANA operations are undoable.

    Can I use KARIANA while the game is playing?#

    Most features work during Play In Editor (PIE). Some editor-only features may be limited.

    How do I stop a long operation?#

    Close Claude Desktop or stop the operation in UE. KARIANA operations respect cancellation.

    Features#

    Can KARIANA create entire games?#

    KARIANA is a tool, not a game generator. It helps with specific tasks like level design, lighting, and prototyping. Creating a complete game requires human creativity and design.

    Does KARIANA support C++?#

    KARIANA primarily works with editor operations. For C++ code generation, you'd use Claude directly, not through KARIANA.

    Can I use custom meshes?#

    Yes, reference them by their content path:

    "Spawn an actor with mesh /Game/MyMeshes/Chair"

    Does KARIANA work with Marketplace assets?#

    Yes, any asset in your project can be referenced.

    Can KARIANA create animations?#

    Limited support through Sequencer tools. Full animation creation is not yet supported.

    Performance#

    Is KARIANA slow?#

    Most operations complete in milliseconds. Complex operations (like building lighting) take as long as they would manually.

    Does KARIANA affect editor performance?#

    Minimal impact. The socket server uses negligible resources when idle.

    Can I use KARIANA on large projects?#

    Yes, but operations on many actors may take longer. Use batch operations and organization for best results.

    Troubleshooting#

    "UE_NOT_CONNECTED" error#

    1. Ensure Unreal Engine is running with a project open
    2. Check that Remote Control plugins are enabled
    3. Verify ports 30010 and 9877 aren't blocked

    See Troubleshooting for more solutions.

    Claude can't find KARIANA tools#

    1. Check your Claude Desktop config file
    2. Verify JSON syntax
    3. Restart Claude Desktop completely

    Commands work but nothing happens#

    1. Check you're in the right level
    2. Verify actor names are correct
    3. Look in Output Log for errors

    Security#

    Is KARIANA safe to use?#

    Yes. KARIANA only responds to local connections by default. It cannot be accessed remotely unless you explicitly configure it.

    Does KARIANA send data anywhere?#

    No. All communication is local between Claude Desktop, the MCP server, and Unreal Engine.

    Can KARIANA delete my files?#

    KARIANA only operates within Unreal Engine. It can delete assets within UE but not arbitrary files on your system.

    Development#

    Can I extend KARIANA?#

    Yes! KARIANA is open source. You can add custom tools by modifying the Python handlers.

    How do I report bugs?#

    Open an issue on GitHub with:

    • Steps to reproduce
    • Expected vs actual behavior
    • UE and KARIANA versions

    Can I contribute?#

    Yes! See the Contributing Guide.

    Comparison#

    How is KARIANA different from Unreal's AI features?#

    Unreal's built-in AI features focus on runtime game AI (behavior trees, etc.). KARIANA is for editor-time operations controlled by an external AI assistant.

    Why use KARIANA instead of Blueprints?#

    Different use cases:

    • Blueprints: Permanent game logic
    • KARIANA: Rapid prototyping, level design, bulk operations

    They complement each other.

    Can KARIANA replace a level designer?#

    No. KARIANA is a tool that helps level designers work faster. Human creativity and design sense are still essential.
