    1. UI Widget Tree#

    The complete containment hierarchy of the Kariana chat panel:

    SDPIScaler (CTRL+scroll font scale 1.0-2.0)
+-- SOverlay (2 layers)

    +--- LAYER 0: Main Chat Panel --------------------------------------+
    |                                                                    |
    | SVerticalBox                                                       |
    | |                                                                  |
    | +- [AutoHeight] HEADER BAR --------------------------------------- |
    | |  SBorder (KarianaBgRaised) + SBox[Height=40]                     |
    | |  +- SHorizontalBox                                               |
    | |     +- [Auto] Menu Button (hamburger icon, 24x24)                |
    | |     +- [Fill] Model Selector (SComboBox, flat transparent style) |
    | |     +- [Auto] Provider Status                                    |
    | |        +- STextBlock (provider name: "Claude", "AWS", etc.)      |
    | |        +- SBox[8x8] -> SBorder (status dot, color-coded)         |
    | |                                                                  |
    | +- [AutoHeight] TOOLBAR ------------------------------------------ |
    | |  SBorder + SBox[Height=32]                                       |
    | |  +- SHorizontalBox                                               |
    | |     +- New Chat (icon button)                                    |
    | |     +- Separator (SBox[1x20])                                    |
    | |     +- Undo (icon button)                                        |
    | |     +- Redo (icon button)                                        |
    | |     +- Separator                                                 |
    | |     +- SKarianaRecordingWidget (REC button + dialog)             |
    | |     +- Spacer (FillWidth=1.0)                                    |
    | |     +- Bug Report (icon button)                                  |
    | |     +- Dashboard (icon button)                                   |
    | |     +- Settings (icon button)                                    |
    | |                                                                  |
    | +- [FillHeight] CONTENT AREA ------------------------------------- |
    | |  SWidgetSwitcher (index 0 or 1)                                  |
    | |  |                                                               |
    | |  +- [0] WELCOME SCREEN (no messages)                             |
    | |  |  +- SKarianaWelcomeScreen                                     |
    | |  |     +- SVerticalBox                                           |
    | |  |        +- STextBlock ("Hey, start with:")                     |
    | |  |        +- 5x Prompt Cards (SButton -> SBorder[rounded])       |
    | |  |           +- STextBlock (prompt text)                         |
    | |  |           +- SButton (pencil edit icon, 16x16)               |
    | |  |                                                               |
    | |  +- [1] MESSAGE LIST (has messages)                              |
    | |     +- SScrollBox (auto-scroll)                                  |
    | |        +- [Dynamic] Message widgets:                             |
    | |                                                                  |
    | |           +- SKarianaChatMessage (Role=User)                     |
    | |           |  +- SBox[Right, MaxWidth=350]                        |
    | |           |     +- SBorder[UserPillBg, Pad 12,8]                 |
    | |           |        +- SMultiLineEditableText (readonly)          |
    | |           |                                                      |
    | |           +- SKarianaChatMessage (Role=Processing)               |
    | |           |  +- SBox[Left] -> SHorizontalBox                     |
    | |           |     +- SBorder (green dot 6x6)                      |
    | |           |     +- STextBlock ("KARIANA is thinking")            |
    | |           |                                                      |
    | |           +- SKarianaChatMessage (Role=Assistant)                |
    | |           |  +- SBox[Left] -> SVerticalBox                       |
    | |           |     +- SKarianaMarkdownRenderer (content)            |
    | |           |     |  +- SVerticalBox (block container)             |
    | |           |     |     +- Paragraphs (SRichTextBlock)             |
    | |           |     |     +- Headers H1-H3 (styled STextBlock)      |
    | |           |     |     +- Code blocks (mono + copy button)       |
    | |           |     |     +- Lists (ordered/unordered)               |
    | |           |     |     +- Tables (SGridPanel)                     |
    | |           |     |     +- Blockquotes (SBorder + accent bar)     |
    | |           |     |     +- Callouts (colored note/tip/warn/etc.)  |
    | |           |     |     +- Horizontal rules                       |
    | |           |     |     +- Images (SKarianaImagePreview)           |
    | |           |     +- ImagesContainer (standalone images)           |
    | |           |     +- StateLabel ("[Cancelled]" / "[Error]")        |
    | |           |     +- Action buttons bar                            |
    | |           |        +- StatsLabel ("Time: Xs | Tools: N")        |
    | |           |        +- Copy button                                |
    | |           |        +- Thumbs up                                  |
    | |           |        +- Thumbs down                                |
    | |           |                                                      |
    | |           +- SKarianaStepsWidget (tool activity)                 |
    | |           |  +- SBox[Left, Pad 8,4,40,4]                        |
    | |           |     +- Thinking bubble (dot + "thinking..." + spin) |
    | |           |     +- StreamingPreview (italic, 120 char max)      |
    | |           |     +- StepsContainer (collapsible)                 |
    | |           |     |  +- [Dynamic] Step rows                       |
    | |           |     |     +- AccentBar (2px left edge, color-coded) |
    | |           |     |     +- Status icon (check/cross/throbber)     |
    | |           |     |     +- Label + Detail (expandable on click)   |
    | |           |     |     +- Timing label ("0.12s")                 |
    | |           |     +- Toggle ("Show N activities" / "Hide...")     |
    | |           |                                                      |
    | |           +- SKarianaUserInputPrompt (approval requests)        |
    | |              +- Header (icon + title)                            |
    | |              +- Question text                                    |
    | |              +- Context preview (expandable)                     |
    | |              +- SKarianaChoiceCards (A/B/C cards)                |
    | |              +- Custom input (if allowed)                        |
    | |              +- Action buttons (approve/deny/custom)            |
    | |                                                                  |
    | +- [AutoHeight] MODE SELECTOR ------------------------------------ |
    | |  SKarianaModeSelector                                            |
    | |  +- SBorder[ModeContainer, Pad 3] + SBox[Height=32]             |
    | |     +- SHorizontalBox (3 equal FillWidth)                        |
    | |        +- VALIDATE pill (green accent)                           |
    | |        +- TEACH pill (yellow accent)                             |
    | |        +- CREATE pill (orange accent)                            |
    | |                                                                  |
    | +- [AutoHeight] INPUT AREA --------------------------------------- |
    | |  SKarianaDropTarget (drag-drop wrapper)                          |
    | |  +- SVerticalBox                                                 |
    | |     +- SKarianaAttachmentBar (chips, collapses when empty)       |
    | |     |  +- SWrapBox -> [Dynamic] Attachment Chips                 |
    | |     |     +- SBorder[rounded] + icon + name + remove(x)          |
    | |     +- SKarianaChatInput                                         |
    | |        +- SBorder[rounded, pink focus border]                    |
    | |           +- SHorizontalBox                                      |
    | |              +- SImage (Kariana logo, 27x27)                     |
    | |              +- SMultiLineEditableTextBox (placeholder text)     |
    | |              +- SButton (send/stop pill, 32x32, pink bg)        |
    | |                                                                  |
    | +- [AutoHeight] PROCESSING LOG (expandable, settings-gated) ----- |
    | |  SExpandableArea (gated: bShowProcessingLog)                     |
    | |  +- SBox[MaxDesiredHeight=180]                                   |
    | |     +- SKarianaProcessingLog                                     |
    | |        +- SListView (log entries: timestamp + color-coded msg)   |
    | |                                                                  |
    | +- [AutoHeight] CONTEXT BAR (status footer) --------------------- |
    |    SKarianaContextBar                                              |
    |    +- SBorder[BgBase, Pad 8,4]                                     |
    |       +- SHorizontalBox                                            |
    |          +- "Level: {map}" (8pt, dim)                              |
    |          +- "Selected: {N}" (8pt, dim)                             |
    |          +- Spacer                                                  |
    |          +- SCircularThrobber (if processing)                      |
    |          +- "Processing log v" (8pt, dim)                          |
    |                                                                    |
    +--- LAYER 1: History Overlay (full panel, toggle) -----------------+
       SKarianaHistoryPanel                                              |
       +- SBorder[BgBase] -> SVerticalBox                                |
          +- Back button (arrow) + "Recent chats" title                  |
          +- SScrollBox -> grouped entries                               |
             +- Section: "TODAY" / "YESTERDAY" / "THIS WEEK" / "OLDER"  |
             +- Entry: title + relative time + delete button             |
                                                                         |
    +--- SEPARATE: Status Overlay (ORPHANED -- never instantiated) -----+
    | SKarianaStatusOverlay                                              |
    | +- Enable checkbox + status icon + "KARIANA" label + model combo  |
    | +- Spinner + status text ("Ready" / "Processing...")              |
    | +- Expandable -> SKarianaProcessingLog (MaxEntries: 100)           |
    |                                                                    |
    | NOTE: This widget exists as complete code (.h + .cpp) but is      |
    | never instantiated by SKarianaChatPanel or any other widget.       |
    | Its functionality has been absorbed into the main ChatPanel        |
    | header, ContextBar, and the SExpandableArea-wrapped               |
    | ProcessingLog. Candidate for removal or future reuse.             |
