    KARIANA v0.9-rc Team Onboarding#

    Claude Code Prompt (copy-paste this to your team)#

    You are onboarding a developer to the KARIANA v0.9 release candidate plugin for Unreal Engine 5.7.

## Setup Steps

1. **Pull the latest developer branch:**
   ```bash
   cd <your-kariana-plugin-directory>
   git checkout developer
   git pull origin developer
   ```

2. **Verify version:**
   Open `KARIANA.uplugin` and confirm `"VersionName": "0.9.0"` and `"Version": 90`.

3. **Set up Baseten API key** (required for KARIANA LLM v0.9):
   Set the environment variable before launching Unreal Engine:
   ```bash
   # Windows (PowerShell)
   $env:KARIANA_BASETEN_API_KEY = "<team-api-key>"

   # Windows (CMD)
   set KARIANA_BASETEN_API_KEY=<team-api-key>

   # macOS/Linux
   export KARIANA_BASETEN_API_KEY=<team-api-key>
   ```
   For persistent setup, add this to your system environment variables or shell profile.

4. **Open your UE project** with the KARIANA plugin installed.

5. **Verify in-editor:**
   - Go to `Edit > Project Settings > KARIANA Assistant`
   - Set Provider to **Baseten (Cloud Inference)**
   - The model dropdown should show **"KARIANA LLM v0.9"**
   - Open the KARIANA chat panel and send a test message: "What tools are available?"
   - Confirm you receive a response from the Baseten endpoint

6. **Test Bedrock fallback (if configured):**
   If you also have `BEDROCK_ENDPOINT` configured, the plugin uses dual-backend routing:
   - KARIANA LLM v0.9 handles reasoning tasks (Verify/Teach modes)
   - Bedrock/Haiku handles tool execution (Standard/Create/Plan modes)

## v0.9 Release Candidate Rules

This is a **release candidate** — the codebase is now locked for stability:

- **NO new features** — only bug fixes, tests, and evals
- All PRs must target the `developer` branch
- Prefix PR titles with `[v0.9-fix]`
- Focus areas: stability, test coverage, evaluation benchmarks
- Report any issues with KARIANA LLM inference, tool calling, or UI regressions

## Key Changes in v0.9

- **KARIANA LLM v0.9**: Our reasoning model (formerly "Nemotron 120B"), hosted on Baseten
- **Ultrathink Pipeline**: 3-tier system — Sonnet 4.6 plans → KARIANA LLM revises → Haiku executes
- **UI Redesign**: New ThemeManager, StyleSets, toolbar, plan/choice cards
- **ECA-Style Commands**: Structured AI commands via C++ MCP HTTP server
- **Blueprint-Lisp**: LISP DSL for creating Blueprint graphs in single tool calls

## Troubleshooting

- **"KARIANA LLM v0.9" not appearing**: Ensure `KARIANA_BASETEN_API_KEY` is set before launching UE
- **Inference timeout**: Check Baseten dashboard for API key validity and rate limits
- **Tool calls failing**: KARIANA LLM routes tool execution to Bedrock/Haiku — ensure both backends are configured if using dual-backend mode
- **Build errors after pull**: Delete `Intermediate/` and `Binaries/` in the plugin folder, then rebuild
