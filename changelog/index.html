    Changelog#

    All notable changes to KARIANA are documented here.

    The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.

    [0.12.0] - 2026-05-26#

    Added#

    • PCG node-wiring. The assistant can now connect the nodes in a PCG graph it builds — sampler to transform to spawner — so the graph generates right away instead of opening with disconnected nodes.
    • Client support bundle — export a redacted diagnostics zip (logs and versions, secrets scrubbed) in one click to share when you need support.
    • Unreal Engine 5.8 support — the plugin now runs on UE 5.8 as well as 5.7.

    Changed#

    • Cleaner chat: each assistant turn is grouped into a single, correctly ordered message.
    • You can queue a follow-up message while the model is still replying.

    Fixed#

    • Windows sign-in no longer freezes on login.
    • Chat now shows every tool step in order, with an accurate tool counter and no silent steps.
    • Fixed a premature "finished" state and an incorrect backend label in the chat panel.
    • The in-editor "update available" banner now clears correctly after you install an update.

    [0.8.28] - 2026-03-06#

    Added - Cinematic Camera Presets#

    • 14 real-world cinema camera presets — ARRI ALEXA 35, ALEXA Mini LF, ALEXA 65, Sony VENICE 2, RED V-Raptor, RED Komodo-X, Sony BURANO, Sony FX6, Canon EOS C400, Canon EOS C70, Blackmagic URSA Cine 12K LF, Blackmagic Pocket 6K G2, Fujifilm GFX ETERNA 55, iPhone 17 Pro Max (PR #264)
    • 3 camera tiers — High-End, Mid-Range, Indie for different production scales
    • 2 new MCP tools — list_cinematic_cameras (with tier filtering) and spawn_cinematic_camera (configures filmback, focal length, aperture, ISO, shutter speed, EV range, Auto Exposure Histogram)
    • 3 bonus camera tools — create_camera_push_shot, focus_viewport_on_actor, sync_viewport

    Added - Camera Framing Skill#

    • Bone-based shot placement — spawns CineCameraActors for 7 standard cinematography shot types (ECU, CU, MCU, MS, CS, MFS, FS) using actual skeleton bone positions for accurate framing (PR #276)
    • Master Sequence creation — creates a Level Sequence with Shot Track containing each shot as a sub-sequence with Camera Cut Track
    • Look At eye tracking — optional TargetPoint-based eye tracking via CineCameraActor LookAt settings with relative offset to preserve framing

    Added - PBL Photorealistic Lighting#

    • 57 validated PBL presets — 25 outdoor + 32 interior presets with scientifically accurate lux values from NOAA, CIE, NIST, and Wikipedia public domain data (PR #267)
    • Sky Atmosphere Mie scattering — overcast and cloudy looks without changing sun intensity, using physically correct atmospheric diffusion
    • Deterministic execution hooks — all PBL tools use @deterministic_tool / @deterministic_resource decorators with input hashing, parameter validation, physical bounds clamping, and audit trail logging
    • 5 new MCP tools — create_lighting_scenario, query_lighting_presets, backup_current_lighting, restore_lighting_backup, adjust_lighting_intensity
    • 4 PBL tools registered — pbl_list_presets, pbl_apply_preset, pbl_spawn_rig, pbl_set_exposure (existing, now formally registered with deterministic wrappers)

    [0.8.27] - 2026-03-06#

    Fixed - UE5.7 Compatibility#

    • UpdateChecker API fix — KarianaUpdateChecker updated for UE5.7 API changes that broke version checking on startup (PR #244)

    [0.8.16] - 2026-03-03#

    Added - Dual-MCP Architecture#

    • Dual-MCP server architecture — KARIANA now runs two MCP servers for Claude Code/Desktop: kariana-unreal (85 tools via socket on port 9877) and kariana-remote (114 tools via Remote Control HTTP on port 30010), totaling 199 tools across both servers (PR #240)
    • 8 previously hidden tools exposed via kariana-remote — tools that were registered but not accessible are now available through the Remote Control HTTP transport
    • Remote Control Python execution — bEnableRemotePythonExecution=True shipped in Config/DefaultEngine.ini for zero-config RC HTTP access

    Fixed - Dual-MCP Stability#

    • Fix exec() entry point bug — package entry points (kariana-mcp, kariana-remote) now pass __name__='__main__' to exec() so if __name__ == "__main__": guards work correctly (previously servers silently exited)
    • Fix dynamic proxy tool registration for FastMCP 2.x compatibility
    • Fix triple execution, temp file races, and module side effects in kariana-remote server

    [0.8.15] - 2026-03-03#

    Added - Installer Improvements#

    • "Install to Project" option for Windows installer — users can now install KARIANA directly into a specific UE project's Plugins/ folder instead of only engine-wide (PR #239)

    Fixed - PowerShell 5.1 Compatibility#

    • Fix upload-plugin-binaries.ps1 for PowerShell 5.1: nested Join-Path calls (3+ args only works in PS 6+), $LASTEXITCODE checks for native commands, @() wrapping for single-item arrays (PR #237)

    [0.8.14] - 2026-03-03#

    Fixed - CI#

    • Fix error handling for binary download in build-installers.yml — workflow now fails with a clear error message when pre-built binaries are missing instead of producing a broken installer (PR #234)

    [0.8.13] - 2026-03-03#

    Fixed - Installer#

    • Manual UE path selection — when Unreal Engine auto-detection fails, the installer now shows a folder picker dialog instead of blocking with an error, with option to skip UE integration entirely (PR #231)

    [0.8.12] - 2026-03-03#

    Added - Pre-Built Binaries for Installer#

    • Binary upload script (scripts/upload-plugin-binaries.ps1) — developers build locally in Rider and upload compiled DLLs to a versioned GitHub release for the installer workflow to download (PR #226)
    • CI binary download — build-installers.yml Windows job downloads matching pre-built binaries and includes them in the installer, bringing installer size from ~2.7MB to ~15MB with working DLLs
    • Dev pre-release build documentation added to release workflow guide

    [0.8.11] - 2026-03-02#

    Fixed - CI#

    • Correct Inno Setup source paths — .iss file paths updated to use ..\..\..\ (3 levels up) to reach repo root from installers/windows/inno-setup/
    • Add plugin staging step in CI workflow — copies KARIANA.uplugin, Source/, Content/, Config/, Resources/ into Plugins/KARIANA/ before ISCC runs

    [0.8.10] - 2026-03-02#

    Added - Documentation#

    • Dev pre-release builds section added to release workflow documentation (PR #217)

    [0.8.9] - 2026-03-02#

    Added - Multi-Platform Installers#

    • Platform installers — Windows .exe (Inno Setup), macOS .tar.gz, Linux .tar.gz installers built via build-installers.yml workflow (PR #207)
    • Rolling dev pre-releases — manual dispatch publishes a dev-latest pre-release on GitHub, replacing the previous build automatically
    • Stable download URL — github.com/INGIPSA/KARIANA/releases/tag/dev-latest always points to the latest dev build

    [0.8.8] - 2026-03-01#

    Added - Sub-Level & World Partition Management#

    • 8 classic sub-level tools — list_sublevels, get_sublevel_info, create_sublevel, delete_sublevel, rename_sublevel, set_sublevel_transform, move_actors_to_sublevel, set_sublevel_streaming_method
    • 10 World Partition tools — get_wp_info, list_data_layers, create_data_layer, delete_data_layer, assign_actors_to_data_layer, remove_actors_from_data_layer, set_data_layer_state, list_streaming_sources, configure_streaming_source, generate_hlod
    • 3 existing tools extended — get_all_scene_objects, spawn_object, search_actors accept optional target_level parameter for scoped operations
    • Shared level utilities (utils/level_utils.py) — world type detection, level resolution, PIE guard, streaming level compat for UE5.7

    Fixed - UE5.7 Python API Compatibility#

    • Replace removed world.get_streaming_levels() with get_streaming_levels_compat() using unreal.find_object() enumeration
    • Wrap get_world_asset_package_f_name() with str() to prevent unreal.Name JSON serialization crash
    • Use create_new_streaming_level() instead of add_level_to_world() (which doesn't load in UE5.7)
    • Fix move_actors_to_level() dest parameter: pass LevelStreaming, not ULevel
    • Replace removed streaming_method property with disable_distance_streaming editor property
    • Replace blocking time.sleep() polling with synchronous editor APIs to avoid game-thread deadlock

    [0.8.7] - 2026-03-01#

    Added - Offline Asset Toolkit#

    • 9 offline asset tools — search, inspect, index, trace references, list, classify, and browse .uasset files without the Unreal Editor running
    • SQLite FTS5 index — full-text search across project assets with type filtering and inheritance queries
    • Blueprint graph inspection — extract and summarize Blueprint node graphs from .uasset binary data
    • C++ source indexing — index header and source files for cross-language reference tracing
    • Adapted from UE-Agent-Asset-Toolkit (MIT License, Braden League)

    [0.8.6] - 2026-03-01#

    Fixed - CI#

    • Bot PR check runs — auto-version bump PRs (created with GITHUB_TOKEN) now generate a successful claude-review check run via the GitHub Check Runs API, preventing branch protection from blocking merge

    [0.8.5] - 2026-02-28#

    Added - Chat UI / UX Polish#

    • Copy button on assistant bubbles — one-click clipboard copy of any KARIANA response; button sits below the message bubble with no visual flash on click
    • Thumbs up / down feedback buttons — rate individual responses directly in the chat panel (▲ / ▼ icons placed to the right of the Copy button with a separator)
    • Text selection in chat bubbles — assistant message text is now selectable so users can highlight and copy specific passages
    • Ctrl+Scroll font resize — hold Ctrl and scroll the mouse wheel over any chat bubble to increase or decrease the rendered font size

    Added - AWS Bedrock Backend#

    • Full AWS Bedrock provider (bedrock_backend.py + KarianaBedrockBridge.cpp) — routes assistant requests through a Lambda-backed API Gateway to the Bedrock Converse API
    • Bedrock daemon adapter — BedrockDaemonAdapter wires the Bedrock backend into the existing daemon loop without changing the Claude Code path
    • Qwen3 tool-calling support — converts MCP tool schemas to OpenAI format for Qwen3 models; all 90+ MCP tools available to Bedrock providers
    • Unauthenticated request rejection — Bedrock API endpoint rejects requests with a missing or empty user ID; the C++ bridge hard-fails before the HTTP call if KarianaUserId is empty

    Added - Editor Controls#

    • Play in Editor MCP tools — three new tools: play_in_editor, simulate_in_editor, and stop_play allow the AI to start and stop PIE sessions programmatically

    Added - Settings#

    • Temperature setting — UKarianaAssistantSettings::Temperature (0.0–1.0, default 0.7) controls response creativity and is wired to both the Claude Code and Bedrock providers
    • Max Agent Turns setting — UKarianaAssistantSettings::MaxAgentTurns (1–100, default 25) caps the agent tool-calling loop to prevent runaway execution

    Security#

    • Socket auth token redaction — the auth token is now shown as only the first 6 characters in startup logs to avoid leaking secrets

    Changed#

    • Default model updated to claude-sonnet-4-6 across settings and Bedrock model dropdown
    • Brand name standardized to KARIANA (all-caps) across all source files, installers, and module names; fixes a Linux include-path case-sensitivity regression

    [0.8.2] - 2026-02-16#

    Added - AI Provider Backends (Experimental)#

    • LM Studio backend (openai_compat_backend.py) — connects to an LM Studio server via the OpenAI-compatible /v1/chat/completions endpoint. Available in Project Settings as LM Studio (Experimental). Default URL: http://localhost:1234
    • Ollama backend — same OpenAICompatibleBackend base class. Available in Project Settings as Ollama (Experimental). Default URL: http://localhost:11434
    • Gradio admin dashboard (Content/Python/admin_dashboard/app.py) — internal web UI at http://localhost:7860 for managing tool category filtering, model selection, and connection testing
    • Auto-restart on provider change — the daemon automatically restarts when the AI provider settings change in Project Settings, eliminating the need to reopen the editor

    Added - Undo / Redo System#

    • Undo/Redo MCP tools — undo, redo, and get_action_history tools let the AI reverse or replay engine actions
    • Undo/Redo toolbar buttons — Undo and Redo buttons added to the KARIANA chat panel toolbar
    • Auto-tool journaling — the daemon wraps every tool call in an UE transaction group so individual AI actions can be undone with a single Ctrl+Z
    • Transaction Manager and Action Journal — TransactionManager and ActionJournal classes track executed tool operations in undo_manager.py

    Added - Chat UI Redesign#

    • Brand-themed chat UI — new bubble layout with KARIANA brand colors, sender avatars, mode selector, and conversation history (PR #107)
    • Mode selector — users can switch between Create / Edit / Ask modes from the chat panel header
    • Markdown rendering system — SKarianaMarkdownRenderer renders assistant responses as rich text with headers, bold/italic, code blocks, tables, callout boxes, and grid lines
    • Theme system — JSON-backed theme with Gradio selector and live hot-reload into the Slate UI; theme auto-stops Gradio on editor close
    • Emoji filtering — centralized emoji stripping applied to MCP tool responses returned from Unreal Engine, preventing emoji characters from polluting LLM context

    Added - Lighting#

    • PBL preset system — 50+ physically-based lighting presets across outdoor and interior scenarios, available via the pbl_apply_preset MCP tool
    • PBL tools registered — pbl_list_presets, pbl_spawn_rig, pbl_set_exposure, and related tools registered in both the MCP server and socket dispatcher

    Added - Infrastructure#

    • FastMCP 2.14.5 migration — MCP server updated to fastmcp>=2.14.5,<3.0.0; a custom ResponseLimitingMiddleware added to replace a removed built-in that broke on that release
    • Backend-agnostic tool management — tool category filtering works across all backend providers without provider-specific code paths

    Added - Enterprise (Research / In Progress)#

    • License validation research — early exploration of HMAC-SHA256 signed JSON license files (Content/Python/licensing/); minimal protection approach still under investigation, not yet production-ready
    • Enterprise build script — Nuitka-compiled build pipeline prototype with license key patching; part of ongoing licensing research
    • C++ bridge license discovery — the C++ bridge locates and passes the license file path to the daemon on startup; dependent on final licensing design

    Added - Web Dashboard#

    • Web dashboard — Clerk auth, API key management, and session UI (feat/web-dashboard branch, added Feb 18)
    • Anthropic API key settings — optional API key field in Project Settings for direct Anthropic API access without the Claude CLI

    [0.8.1] - 2026-02-06#

    Added - SpecialAgentPlugin-Inspired Features#

    • Navigation Service (3 tools)
    • rebuild_navmesh: Rebuild NavMesh with optional bounds
    • test_pathfind: Test pathfinding between two points

    • get_navmesh_info: Get NavMesh coverage and statistics

    • Patterns Service (5 tools)

    • spawn_pattern_grid: Spawn actors in grid layout
    • spawn_pattern_circular: Spawn actors in circular/arc pattern
    • spawn_pattern_spline: Spawn actors along a path/spline
    • spawn_pattern_scatter: Random scatter with min distance

    • spawn_pattern_surface: Surface-projected placement

    • Streaming Service (4 tools)

    • list_streaming_levels: List all streaming levels
    • load_streaming_level: Load streaming level
    • unload_streaming_level: Unload streaming level

    • set_streaming_level_visibility: Toggle level visibility

    • Foliage Service (4 tools)

    • get_foliage_types: List available foliage types
    • paint_foliage: Paint foliage instances
    • remove_foliage: Remove foliage in area

    • create_foliage_type: Create new foliage type

    • Spatial Service (3 tools)

    • find_actors_in_radius: Find actors within radius
    • find_overlapping_actors: Find actors in bounds

    • detect_overlaps_batch: Detect overlapping actors

    • Spatial Patterns Skill

    • Expert knowledge for pattern selection
    • Workflows: quick-scatter, grid-placement, path-placement
    • Automatic activation on spatial keywords

    Changed#

    • Tool count: 199+ → 218+
