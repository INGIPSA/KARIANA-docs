    Phase 5: Layout Constants#

    Risk: Low-Medium -- mechanical replacement, no logic changes. Files touched: ~17 Depends on: Phase 1 (cleanup). Independent of Phases 2-4 but should follow for consistency.

    Design#

    Create KarianaLayoutConstants.h with named constants replacing ~195 magic numbers.

    Migration Approach#

    Mechanical find-and-replace per widget file. Example:

    // BEFORE:
SNew(SBox).HeightOverride(40)
// AFTER:
SNew(SBox).HeightOverride(KarianaLayout::HeaderHeight)

// BEFORE:
FMargin(12, 4)
// AFTER:
KarianaLayout::Message::AssistantPadding
