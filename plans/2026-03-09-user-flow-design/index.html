    KARIANA User Flow Design#

    Date: 2026-03-09 Status: Draft — validated through brainstorming, pending team review

    Overview#

    Complete user journey for KARIANA, covering both free (Open Core) and enterprise paths. Enterprise is the primary focus. Discovery is currently social-driven (LinkedIn, word of mouth, kariana.ai). An open-source version with limited tools will serve as a future funnel.

    Pricing Tiers (6 tiers)#

    Tier LLM Infra Price/seat/mo Key Differentiators
    Open Core BYOM — $1 CREATE mode only, basic tools, no dashboard
    Solo (Cloud) Cloud (KARIANA) KARIANA cloud $159 All features, unlimited fair usage
    Team (Cloud) Cloud (KARIANA) KARIANA cloud $75-149 Admin panel, audit logs, NDA mode, volume discount
    BYOM Cloud Cloud (client) Client cloud $99-175 Client's own cloud LLM, version control integration
    Local LLM Local Client hardware $99-175 On-premise, local models, same features
    Local LLM + HW Local KARIANA hardware $99-175 KARIANA-provided hardware, YubiKey 2FA

    Token limits: - Solo: 500 ops/day, 4M tokens/month - Team: 300 ops/user/day - Enterprise: 10M tokens/user/month - After limit: degrades to Haiku (no hard block)

    Professional services: On-premise install (\(10K), Pipeline Audit (\)8K), Workshops (\(3.5K-\)6K), Full Audit + Implementation (\(12K-\)15K), Custom Hardware (\(5.6K-\)36K), Consulting ($260/h)

    Complete Journey Summary#

    Discovery --> kariana.ai --> Pricing --> Signup --> Plan + Pay
    --> API Key + Email --> Install (per platform) --> Enter Key
    --> Launch UE --> Tutorial (optional) --> Checklist (optional)
    --> Daily Use --> Token tracking --> Degradation warnings
    --> Upgrade paths (self-serve or professional services)

Enterprise adds: Admin dashboard, team invites, audit logs, NDA mode

    Key Findings#

    1. External dependencies: Landing page, signup, payment, and team dashboard all live on app.kariana.ai (Next.js, not in this repo)
    2. Strongest areas: Licensing system is production-ready; Welcome screen ships with plugin; Installers work on all 3 platforms
    3. Critical gaps for MVP: API key in installer, token tracking + degradation, onboarding checklist, upgrade prompts
    4. Architecture ready but disconnected: Settings class has API key field but daemon PR pending; NDA sanitizer done but not wired; Clerk whitelisted but no auth flow
