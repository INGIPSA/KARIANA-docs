    Plugin Auto-Update Implementation Plan#

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

    Goal: Replace the current manual "open download page" flow with a real auto-update — background download, integrity verify, restart prompt, in-place swap — scoped narrowly enough to be safe in alpha.

    Architecture: Project-install-only auto-update on the GitHub-zip alpha channel. Engine installs, Marketplace installs, and KARIANA-installer-managed installs detect themselves and fall back to the existing manual flow. Cross-platform file swap is performed by an external bootstrapper binary that runs after the editor exits, reads a swap-manifest written by the editor, performs the swap atomically, optionally relaunches the editor, and self-deletes. This avoids the Windows-only "rename-locked-DLL" trick and eliminates the half-installed failure mode.

    Tech Stack: UE 5.7 C++ (HttpModule, FZipFileFunctions where available else third-party miniz, IPluginManager, FUnrealEdMisc::RestartEditor), Slate (FNotificationInfo, banner widget), Go or Rust for the bootstrapper binary (single static cross-platform binary, no runtime deps), GitHub Actions for bootstrapper releases. Manifest format already defined: {version, downloadUrl, sha256} from app.kariana.ai/api/version.

    Issue tracker: GitHub INGIPSA/KARIANA #465 (in-place extraction).

    Scope decisions / non-goals: - ❌ Engine plugin auto-update (Engine/Plugins/Marketplace/KARIANA/) → defer to manual installer; UAC + Marketplace conflict + shared-engine teammate breakage make it not worth alpha-cycle complexity. - ❌ Marketplace channel → Epic Launcher owns updates; we must detect and stand down. - ❌ Source-built engine recompile → only DLL swap, never rebuild from source. - ❌ Multi-version skip migration logic → first auto-update release supports N→N+1 only; multi-skip falls back to manual. - ❌ Code signing of the new zip → SHA256 only in v1; Authenticode/notarization comes in a follow-up.

    bool IsSymlink(const FString& Path)
    {
    #if PLATFORM_WINDOWS
        const DWORD Attrs = ::GetFileAttributesW(*Path);
        return (Attrs != INVALID_FILE_ATTRIBUTES) && (Attrs & FILE_ATTRIBUTE_REPARSE_POINT);
    #else
        struct stat St{};
        return lstat(TCHAR_TO_UTF8(*Path), &St) == 0 && S_ISLNK(St.st_mode);
    #endif
    }

    bool IsWritable(const FString& Dir)
    {
        const FString Probe = FPaths::Combine(Dir, TEXT(".kariana-write-probe"));
        if (FFileHelper::SaveStringToFile(TEXT("ok"), *Probe))
        {
            IFileManager::Get().Delete(*Probe);
            return true;
        }
        return false;
    }
}

FKarianaInstallContext FKarianaInstallContext::Detect()
{
    FKarianaInstallContext Ctx;

    TSharedPtr<IPlugin> Plugin = IPluginManager::Get().FindPlugin(TEXT("KARIANA"));
    if (!Plugin.IsValid())
    {
        return Ctx;  // Location = Unknown
    }

    Ctx.PluginBaseDir   = FPaths::ConvertRelativePathToFull(Plugin->GetBaseDir());
    Ctx.PluginParentDir = FPaths::GetPath(Ctx.PluginBaseDir);

    if (IsSymlink(Ctx.PluginBaseDir))
    {
        Ctx.Location = EKarianaInstallLocation::SymlinkedDev;
        return Ctx;
    }

    const FString ProjectPlugins = FPaths::ConvertRelativePathToFull(FPaths::ProjectPluginsDir());
    const FString EnginePlugins  = FPaths::ConvertRelativePathToFull(FPaths::EnginePluginsDir());
    const FString Marketplace    = FPaths::Combine(EnginePlugins, TEXT("Marketplace"));

    if (Ctx.PluginBaseDir.StartsWith(ProjectPlugins))
    {
        Ctx.Location = EKarianaInstallLocation::ProjectPlugins;
    }
    else if (Ctx.PluginBaseDir.StartsWith(Marketplace))
    {
        Ctx.Location = EKarianaInstallLocation::EngineMarketplace;
    }
    else if (Ctx.PluginBaseDir.StartsWith(EnginePlugins))
    {
        Ctx.Location = EKarianaInstallLocation::EngineCustom;
    }

    Ctx.bWritableWithoutElevation = IsWritable(Ctx.PluginParentDir);
    return Ctx;
}

    bool FKarianaInstallContext::CanAutoUpdate(FString& OutReason) const
{
    if (Location == EKarianaInstallLocation::SymlinkedDev)
        { OutReason = TEXT("Plugin directory is a symlink (developer setup) — auto-update disabled."); return false; }
    if (Location == EKarianaInstallLocation::EngineMarketplace || Channel == EKarianaUpdateChannel::Marketplace)
        { OutReason = TEXT("Marketplace install — updates managed by Epic Launcher."); return false; }
    if (Location == EKarianaInstallLocation::EngineCustom)
        { OutReason = TEXT("Engine plugin install — please use the manual installer."); return false; }
    if (Channel == EKarianaUpdateChannel::InstallerManaged)
        { OutReason = TEXT("Installer-managed — please run KARIANA installer."); return false; }
    if (!bWritableWithoutElevation)
        { OutReason = TEXT("Plugin directory is not writable by this user."); return false; }
    if (bSiblingEditorRunning)
        { OutReason = TEXT("Another Unreal Editor is running with KARIANA loaded — close it and try again."); return false; }
    if (Location != EKarianaInstallLocation::ProjectPlugins)
        { OutReason = TEXT("Unsupported install location."); return false; }
    OutReason.Empty();
    return true;
}

struct FKarianaDownloadResult

    Task 1.2: Implement async download with atomic write#

    Files: - Create: Source/UnrealAssistantIntegration/Private/Updates/KarianaUpdateDownloader.cpp

    Key behaviors: - Stream to <staging>/<version>.zip.partial. On complete success, rename to <version>.zip. On failure or cancel, delete partial file. - Disk-space check before starting: require 2 * Content-Length (download + extraction headroom). If unknown, require 500 MB free as conservative default. Use FPlatformMisc::GetDiskSpace. - Cap download size to 500 MB (sanity): refuse if Content-Length > limit. - Idempotency: if <version>.zip already exists with matching SHA256, skip download. - On HTTP redirect: UE's FHttpModule does not follow 3xx by default. Inspect Resp->GetHeader(TEXT("Location")) and re-issue (cap at 3 redirects to avoid loops).

    • Step 1: Implement Start() with idempotency check
    #include "Updates/KarianaUpdateDownloader.h"
#include "HttpModule.h"
#include "Interfaces/IHttpResponse.h"
#include "Misc/Paths.h"
#include "Misc/FileHelper.h"
#include "Misc/SecureHash.h"
#include "HAL/PlatformFileManager.h"

static FString GetStagingDir()
{
    return FPaths::Combine(FPlatformProcess::UserSettingsDir(), TEXT("KARiANA"), TEXT("pending-update"));
}

void FKarianaUpdateDownloader::Start(const FString& Url, const FString& ExpectedSha256, const FString& Version)
{
    Result = FKarianaDownloadResult{};
    Result.ExpectedSha256 = ExpectedSha256.ToLower();
    const FString Dir = GetStagingDir();
    IFileManager::Get().MakeDirectory(*Dir, /*Tree=*/true);
    const FString FinalPath = FPaths::Combine(Dir, FString::Printf(TEXT("%s.zip"), *Version));

    // Idempotency: re-use a prior verified download.
    FString Actual;
    if (FPaths::FileExists(FinalPath) && VerifySha256(FinalPath, Result.ExpectedSha256, Actual))
    {
        Result.Status = EKarianaDownloadStatus::Ready;
        Result.StagedZipPath = FinalPath;
        Result.ActualSha256 = Actual;
        OnProgress.Broadcast(Result);
        return;
    }
    IFileManager::Get().Delete(*FinalPath, /*RequireExists=*/false);

    // Disk-space guard: require >=500 MB free.
    uint64 TotalBytes = 0, FreeBytes = 0;
    FPlatformMisc::GetDiskTotalAndFreeSpace(Dir, TotalBytes, FreeBytes);
    if (FreeBytes < 500ull * 1024 * 1024)
    {
        Result.Status = EKarianaDownloadStatus::Failed;
        Result.FailureReason = TEXT("Less than 500 MB free in staging dir.");
        OnProgress.Broadcast(Result);
        return;
    }

    Result.Status = EKarianaDownloadStatus::InProgress;
    OnProgress.Broadcast(Result);

    const FString PartialPath = FinalPath + TEXT(".partial");
    ActiveRequest = FHttpModule::Get().CreateRequest();
    ActiveRequest->SetURL(Url);
    ActiveRequest->SetVerb(TEXT("GET"));
    ActiveRequest->SetHeader(TEXT("User-Agent"), TEXT("KARIANA-UE-Updater/1"));
    ActiveRequest->OnRequestProgress().BindLambda(
        [this](FHttpRequestPtr Req, int32 Sent, int32 Recv)
        {
            Result.BytesDownloaded = Recv;
            Result.BytesTotal      = Req->GetResponse().IsValid() ? Req->GetResponse()->GetContentLength() : 0;
            OnProgress.Broadcast(Result);
        });
    ActiveRequest->OnProcessRequestComplete().BindLambda(
        [this, PartialPath, FinalPath](FHttpRequestPtr Req, FHttpResponsePtr Resp, bool bOk)
        {
            this->OnHttpComplete(Req, Resp, bOk, FinalPath);
        });
    ActiveRequest->ProcessRequest();
}
    • Step 2: Implement OnHttpComplete (rename partial → final, verify, broadcast)
    void FKarianaUpdateDownloader::OnHttpComplete(FHttpRequestPtr Req, FHttpResponsePtr Resp, bool bConnected, FString FinalPath)
{
    if (!bConnected || !Resp.IsValid() || Resp->GetResponseCode() / 100 != 2)
    {
        Result.Status = EKarianaDownloadStatus::Failed;
        Result.FailureReason = FString::Printf(TEXT("HTTP failure (code=%d)"),
            Resp.IsValid() ? Resp->GetResponseCode() : 0);
        OnProgress.Broadcast(Result);
        return;
    }

    // Write payload atomically: bytes -> .partial -> rename to final.
    const TArray<uint8>& Payload = Resp->GetContent();
    const FString PartialPath = FinalPath + TEXT(".partial");
    if (!FFileHelper::SaveArrayToFile(Payload, *PartialPath))
    {
        Result.Status = EKarianaDownloadStatus::Failed;
        Result.FailureReason = TEXT("Could not write zip to staging dir.");
        OnProgress.Broadcast(Result);
        return;
    }

    Result.Status = EKarianaDownloadStatus::Verifying;
    OnProgress.Broadcast(Result);

    FString Actual;
    if (!VerifySha256(PartialPath, Result.ExpectedSha256, Actual))
    {
        Result.ActualSha256 = Actual;
        Result.Status = EKarianaDownloadStatus::Failed;
        Result.FailureReason = FString::Printf(TEXT("SHA256 mismatch (expected=%s actual=%s)"),
            *Result.ExpectedSha256, *Actual);
        IFileManager::Get().Delete(*PartialPath);
        OnProgress.Broadcast(Result);
        return;
    }

    if (!IFileManager::Get().Move(*FinalPath, *PartialPath, /*bReplace=*/true))
    {
        Result.Status = EKarianaDownloadStatus::Failed;
        Result.FailureReason = TEXT("Could not finalize staged zip.");
        OnProgress.Broadcast(Result);
        return;
    }

    Result.StagedZipPath = FinalPath;
    Result.ActualSha256 = Actual;
    Result.Status = EKarianaDownloadStatus::Ready;
    OnProgress.Broadcast(Result);
}

bool FKarianaUpdateDownloader::VerifySha256(const FString& Path, const FString& Expected, FString& OutActual) const
{
    TArray<uint8> Bytes;
    if (!FFileHelper::LoadFileToArray(Bytes, *Path)) return false;
    FSHAHash Hash;
    FSHA1::HashBuffer(Bytes.GetData(), Bytes.Num(), Hash.Hash);  // SHA-1, NOT SHA-256
    // NOTE: UE's FSHA1 is SHA-1; for SHA-256 use FSHA256 (UE 5.3+) or fall back to OpenSSL.
    // See note in step 3 below — wire FSHA256.
    OutActual = Hash.ToString().ToLower();
    return OutActual == Expected;
}
    • Step 3: Replace SHA-1 with SHA-256

    UE 5.3+ ships FSHA256Hasher (header Misc/SecureHash.h and Hash/Sha256.h depending on engine version). Replace the FSHA1::HashBuffer call with the SHA-256 equivalent:

    #include "Hash/Sha256.h"  // verify path on UE 5.7
// ...
FSha256 Hasher;
Hasher.Update(Bytes.GetData(), Bytes.Num());
FSha256Hash Out = Hasher.Finalize();
OutActual = BytesToHex(Out.Hash, sizeof(Out.Hash)).ToLower();

    If Hash/Sha256.h is not available in 5.7, fall back to the OpenSSL EVP_* API (UE bundles OpenSSL via OpenSSL module — add it to PrivateDependencyModuleNames in UnrealAssistantIntegration.Build.cs).

    # Swap Manifest v1

Written by editor to `<LocalAppData>/KARiANA/swap-manifest.json` immediately
before exiting. Read by the bootstrapper as its single source of truth.

```json
{
  "schema": 1,
  "editor_pid": 12345,
  "plugin_dir": "C:/Users/.../MyProject/Plugins/KARIANA",
  "staged_zip": "C:/Users/.../KARiANA/pending-update/0.10.4.zip",
  "expected_sha256": "abc123...",
  "rename_suffix": ".old-20260430-153012",
  "relaunch": {
    "enabled": true,
    "executable": "C:/Program Files/Epic Games/UE_5.7/Engine/Binaries/Win64/UnrealEditor.exe",
    "args": ["C:/path/to/MyProject.uproject"],
    "working_dir": "C:/path/to"
  },
  "log_path": "C:/Users/.../KARiANA/bootstrapper.log",
  "rollback_marker": "C:/Users/.../KARiANA/last-good-version.txt"
}

    Bootstrapper steps in order: 1. Wait up to 30 s for editor_pid to exit (poll kill -0 / OpenProcess). 2. Re-verify staged_zip SHA256 matches expected_sha256. Abort if not. 3. Validate zip entries: no absolute paths, no .. segments, no symlinks (zip-slip guard). 4. Read existing plugin_dir, rename every file/dir to <name><rename_suffix>. 5. Extract zip into plugin_dir's parent. 6. Verify the new KARIANA.uplugin exists and is parseable. 7. On success: write rollback_marker with the new version, schedule deletion of .old-* files (next launch the plugin's Initialize cleans them up). 8. On any failure between steps 4 and 6: rename .old-* back to original, delete partial extraction. Write detailed log. 9. If relaunch.enabled: spawn the editor process detached and exit.

    bool FKarianaUpdateOrchestrator::SpawnBootstrapper(const FString& ManifestPath)
{
    const FString PluginBaseDir = IPluginManager::Get().FindPlugin(TEXT("KARIANA"))->GetBaseDir();
    const FString BootstrapperPath = FPaths::Combine(PluginBaseDir,
        TEXT("Binaries"),
        FPlatformProperties::PlatformName(),
        FString::Printf(TEXT("kariana-update%s"),
            PLATFORM_WINDOWS ? TEXT(".exe") : TEXT("")));

    if (!FPaths::FileExists(BootstrapperPath))
    {
        UE_LOG(LogKarianaAssistant, Error, TEXT("[KARIANA] Bootstrapper not found at %s"), *BootstrapperPath);
        return false;
    }

    const FString Args = FString::Printf(TEXT("--manifest \"%s\""), *ManifestPath);
    const bool bDetached = true;
    const bool bHidden   = false;
    uint32 OutProcessID = 0;
    FProcHandle Handle = FPlatformProcess::CreateProc(
        *BootstrapperPath, *Args, bDetached, bHidden, /*ReallyHidden=*/false,
        &OutProcessID, /*PriorityModifier=*/0, nullptr, nullptr, nullptr);
    if (!Handle.IsValid()) return false;
    FPlatformProcess::CloseProc(Handle);  // detach
    return true;
}
