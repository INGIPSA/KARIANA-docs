    Python IP Protection — Cython Compilation Pipeline#

    For Claude: REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

    Goal: Compile all sensitive Python sources to native .pyd/.so extensions and enforce per-client Ed25519-signed licenses so distributed plugin binaries reveal no methodology and cannot be shared or forged.

    Architecture: Cython converts .py → C → native extensions. Ed25519 asymmetric signing — private key stays with KARIANA, public key is embedded in the compiled binary so clients cannot forge licenses even if they disassemble it. The daemon auto-discovers the license from OS standard paths — no configuration needed from clients or team members. CI targets Windows (shipped in pre-alpha) with Mac/Linux matrix ready for future delivery.

    Tech Stack: Cython 3.x, setuptools, cryptography (Ed25519), GitHub Actions (windows-latest + macos-latest + ubuntu-latest matrix), Python 3.11 (UE 5.7 embedded version)

"""
One-time Ed25519 keypair generation for KARIANA license signing.
Run ONCE on a secure machine. Never run again unless rotating keys.

    python tools/generate_keypair.py

Outputs:
    licenses/private_key.pem           — NEVER commit. Store in 1Password immediately.
    Content/Python/licensing/public_key.pem  — safe to commit (public half only)

After running, paste the printed DER_B64 value into Content/Python/licensing/core.py
"""
import base64
from pathlib import Path

from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PrivateKey
from cryptography.hazmat.primitives.serialization import (
    Encoding, PrivateFormat, PublicFormat, NoEncryption,
)


def main():
    private_key = Ed25519PrivateKey.generate()
    public_key = private_key.public_key()

    private_pem = private_key.private_bytes(Encoding.PEM, PrivateFormat.PKCS8, NoEncryption())
    public_pem = public_key.public_bytes(Encoding.PEM, PublicFormat.SubjectPublicKeyInfo)
    public_der = public_key.public_bytes(Encoding.DER, PublicFormat.SubjectPublicKeyInfo)
    public_der_b64 = base64.b64encode(public_der).decode("ascii")

    Path("licenses").mkdir(exist_ok=True)
    Path("licenses/private_key.pem").write_bytes(private_pem)
    Path("Content/Python/licensing/public_key.pem").write_bytes(public_pem)

    print("=" * 60)
    print("KEYPAIR GENERATED")
    print("=" * 60)
    print()
    print(">>> STEP 1: Save licenses/private_key.pem to 1Password NOW <<<")
    print()
    print(">>> STEP 2: Paste this line into Content/Python/licensing/core.py <<<")
    print()
    print(f'_PUBLIC_KEY_DER_B64 = "{public_der_b64}"')
    print()
    print("Public key file: Content/Python/licensing/public_key.pem (commit this)")


if __name__ == "__main__":
    main()

    """
License validation for KARIANA Enterprise.

Ed25519 asymmetric signing: private key stays with KARIANA, public key is
embedded here. Clients cannot forge licenses even with full binary access.

Usage:
    from licensing.core import validate_license, load_and_validate, LicenseInfo

    info = load_and_validate("path/to/license.lic")
"""
import base64
import json
import os
from dataclasses import dataclass, field
from datetime import date
from typing import Any, Dict, List

from cryptography.exceptions import InvalidSignature
from cryptography.hazmat.primitives.serialization import load_der_public_key


# ---------------------------------------------------------------------------
# Embedded public key — DER encoded, base64. Generated by tools/generate_keypair.py
# The private key never lives here. Extracting this only gives you the verifier half.
# ---------------------------------------------------------------------------
_PUBLIC_KEY_DER_B64 = "__PASTE_VALUE_FROM_generate_keypair.py_OUTPUT_HERE__"

# ---------------------------------------------------------------------------
# Required license fields
# ---------------------------------------------------------------------------
_REQUIRED_FIELDS = frozenset({
    "license_id", "client", "type", "seats", "issued", "expires", "features",
})


class LicenseError(Exception):
    """Raised when license validation fails."""


@dataclass
class LicenseInfo:
    license_id: str
    client: str
    license_type: str
    seats: int
    issued: date
    expires: date
    features: List[str]
    raw: Dict[str, Any] = field(default_factory=dict, repr=False)

    def has_feature(self, name: str) -> bool:
        return "all" in self.features or name in self.features

    @property
    def is_expired(self) -> bool:
        return date.today() > self.expires

    @property
    def days_remaining(self) -> int:
        return (self.expires - date.today()).days


def _canonical_payload(data: Dict[str, Any]) -> bytes:
    """Deterministic bytes for signature verification — excludes the signature field."""
    filtered = {k: v for k, v in data.items() if k != "signature"}
    return json.dumps(filtered, separators=(",", ":"), sort_keys=True).encode("utf-8")


def _public_key():
    der = base64.b64decode(_PUBLIC_KEY_DER_B64)
    return load_der_public_key(der)


def validate_license(data: Dict[str, Any]) -> LicenseInfo:
    """Validate a license dict. Raises LicenseError on any failure."""
    missing = _REQUIRED_FIELDS - set(data.keys())
    if missing:
        raise LicenseError(f"License missing required fields: {', '.join(sorted(missing))}")

    sig_b64 = data.get("signature")
    if not sig_b64:
        raise LicenseError("License signature is missing")

    try:
        sig_bytes = base64.b64decode(sig_b64)
        _public_key().verify(sig_bytes, _canonical_payload(data))
    except InvalidSignature:
        raise LicenseError("License signature verification failed — license may be tampered or invalid")
    except Exception as e:
        raise LicenseError(f"License verification error: {e}")

    try:
        issued = date.fromisoformat(data["issued"])
        expires = date.fromisoformat(data["expires"])
    except (ValueError, TypeError) as exc:
        raise LicenseError(f"Invalid date format in license: {exc}")

    if date.today() > expires:
        raise LicenseError(f"License expired on {expires.isoformat()}")

    return LicenseInfo(
        license_id=data["license_id"],
        client=data["client"],
        license_type=data["type"],
        seats=data["seats"],
        issued=issued,
        expires=expires,
        features=list(data["features"]),
        raw=dict(data),
    )


def load_and_validate(path: str) -> LicenseInfo:
    """Load a JSON license file from *path* and validate it."""
    if not os.path.isfile(path):
        raise LicenseError(f"License file not found: {path}")
    try:
        with open(path, "r", encoding="utf-8") as fh:
            data = json.load(fh)
    except (json.JSONDecodeError, UnicodeDecodeError) as exc:
        raise LicenseError(f"Failed to parse license file: {exc}")
    return validate_license(data)

    #!/usr/bin/env python3
"""
Generate a signed KARIANA enterprise license file.

Usage:
    python tools/generate_license.py \
        --client "Acme Studios" \
        --type pre_alpha_enterprise \
        --seats 5 \
        --expires 2027-02-25 \
        --features all \
        --key licenses/private_key.pem \
        -o licenses/acme-studios.lic

License ID is auto-generated (KAR-YYYYMM-NNN). Use --id to set manually.
"""
import argparse
import base64
import json
import random
import string
from datetime import date
from pathlib import Path

from cryptography.hazmat.primitives.serialization import load_pem_private_key


def _canonical_payload(data: dict) -> bytes:
    filtered = {k: v for k, v in data.items() if k != "signature"}
    return json.dumps(filtered, separators=(",", ":"), sort_keys=True).encode("utf-8")


def generate_license(client, license_type, seats, expires, features, private_key_path,
                     license_id=None):
    with open(private_key_path, "rb") as f:
        private_key = load_pem_private_key(f.read(), password=None)

    if license_id is None:
        suffix = "".join(random.choices(string.digits, k=3))
        license_id = f"KAR-{date.today().strftime('%Y%m')}-{suffix}"

    data = {
        "license_id": license_id,
        "client": client,
        "type": license_type,
        "seats": seats,
        "issued": date.today().isoformat(),
        "expires": expires,
        "features": features,
    }

    sig_bytes = private_key.sign(_canonical_payload(data))
    data["signature"] = base64.b64encode(sig_bytes).decode("ascii")
    return data


def main():
    parser = argparse.ArgumentParser(description="Generate a signed KARIANA license file")
    parser.add_argument("--client", required=True, help="Client name or company")
    parser.add_argument("--type", default="pre_alpha_enterprise",
                        help="License type (default: pre_alpha_enterprise)")
    parser.add_argument("--seats", type=int, default=1)
    parser.add_argument("--expires", required=True, help="Expiry date YYYY-MM-DD")
    parser.add_argument("--features", nargs="+", default=["all"],
                        help="Feature flags (default: all)")
    parser.add_argument("--id", dest="license_id", default=None,
                        help="Override auto-generated license ID")
    parser.add_argument("--key", default="licenses/private_key.pem",
                        help="Path to Ed25519 private key (default: licenses/private_key.pem)")
    parser.add_argument("-o", "--output", required=True, help="Output .lic file path")
    args = parser.parse_args()

    if not Path(args.key).exists():
        print(f"ERROR: Private key not found at {args.key}")
        print("Run tools/generate_keypair.py first and restore from 1Password.")
        raise SystemExit(1)

    lic = generate_license(
        client=args.client,
        license_type=args.type,
        seats=args.seats,
        expires=args.expires,
        features=args.features,
        private_key_path=args.key,
        license_id=args.license_id,
    )

    Path(args.output).parent.mkdir(parents=True, exist_ok=True)
    Path(args.output).write_text(json.dumps(lic, indent=2))

    print(f"License generated: {args.output}")
    print(f"  License ID : {lic['license_id']}")
    print(f"  Client     : {lic['client']}")
    print(f"  Type       : {lic['type']}")
    print(f"  Seats      : {lic['seats']}")
    print(f"  Expires    : {lic['expires']}")
    print(f"  Features   : {lic['features']}")


if __name__ == "__main__":
    main()

def run_daemon(extra_args=None, env=None, timeout=5):
    """Run daemon as subprocess, capture stdout lines as parsed JSON."""
    cmd = [sys.executable, DAEMON_PATH] + (extra_args or [])
    result = subprocess.run(cmd, capture_output=True, text=True, timeout=timeout, env=env)
    messages = []
    for line in result.stdout.splitlines():
        line = line.strip()
        if line.startswith("{"):
            try:
                messages.append(json.loads(line))
            except json.JSONDecodeError:
                pass
    return result.returncode, messages

    Task 9: Release Packaging Script#

    Step 1: Create the script

    #!/usr/bin/env python3
"""
Package KARIANA plugin for distribution.

Usage:
    python tools/package_release.py \
        --artifacts compiled-artifacts/ \
        --output release/ \
        --platforms windows          # or: windows macos linux (space-separated)

Produces:
    release/KARIANA-Win64.zip        (when --platforms includes windows)
    release/KARIANA-macOS.zip        (future)
    release/KARIANA-Linux.zip        (future)

Each zip contains:
  - All non-protected source files (.py files that are safe to expose)
  - Compiled extensions (.pyd/.so) for that platform
  - NO protected .py sources (handlers/, licensing/, backends secrets, daemon)
"""
import argparse
import zipfile
from pathlib import Path


PROTECTED_PY_FILES = {
    "kariana_agent_daemon.py",
    "mcp_server.py",
    "unreal_socket_server.py",
}

PROTECTED_PY_DIRS = {"handlers", "licensing"}

PROTECTED_BACKEND_FILES = {
    "openai_compat_backend.py",
    "bedrock_backend.py",
    "bedrock_daemon_adapter.py",
    "tool_schema.py",
    "tool_executor.py",
}

PLATFORM_MAP = {
    "windows": ("Win64", ".pyd", "compiled-windows"),
    "macos": ("macOS", ".so", "compiled-macos"),
    "linux": ("Linux", ".so", "compiled-linux"),
}


def is_protected_py(path: Path, repo_root: Path) -> bool:
    """Return True if this .py file must be excluded from the release zip."""
    try:
        rel = path.relative_to(repo_root)
    except ValueError:
        return False
    parts = rel.parts

    # e.g. Content/Python/kariana_agent_daemon.py
    if (len(parts) == 3 and parts[0] == "Content" and parts[1] == "Python"
            and parts[2] in PROTECTED_PY_FILES):
        return True

    # e.g. Content/Python/handlers/blueprint_commands.py
    if (len(parts) >= 4 and parts[0] == "Content" and parts[1] == "Python"
            and parts[2] in PROTECTED_PY_DIRS):
        return True

    # e.g. Content/Python/backends/bedrock_backend.py
    if (len(parts) == 4 and parts[0] == "Content" and parts[1] == "Python"
            and parts[2] == "backends" and parts[3] in PROTECTED_BACKEND_FILES):
        return True

    return False


def build_platform_zip(repo_root: Path, artifact_dir: Path,
                        platform_name: str, ext: str, output_dir: Path):
    zip_path = output_dir / f"KARIANA-{platform_name}.zip"
    print(f"\nPackaging {platform_name} → {zip_path}")
    protected_skipped = 0
    files_added = 0

    with zipfile.ZipFile(zip_path, "w", zipfile.ZIP_DEFLATED) as zf:
        # Walk the full repo and include non-protected files
        for src in sorted(repo_root.rglob("*")):
            if not src.is_file():
                continue
            rel = src.relative_to(repo_root)
            str_rel = str(rel)

            # Skip git, __pycache__, build artifacts, compiled binaries
            if any(part.startswith(".") for part in rel.parts):
                continue
            if "__pycache__" in str_rel or str_rel.endswith(".pyc"):
                continue
            if "build/" in str_rel or str_rel.endswith((".c", ".pyd", ".so")):
                continue

            # Skip protected .py sources — they ship as compiled extensions only
            if src.suffix == ".py" and is_protected_py(src, repo_root):
                protected_skipped += 1
                continue

            zf.write(src, rel)
            files_added += 1

        # Add compiled extensions for this platform
        compiled_count = 0
        for compiled in sorted(artifact_dir.rglob(f"*{ext}")):
            rel_in_artifact = compiled.relative_to(artifact_dir)
            zf.write(compiled, rel_in_artifact)
            compiled_count += 1
            print(f"  + {rel_in_artifact}")

    size_mb = zip_path.stat().st_size / 1024 / 1024
    print(f"  {files_added} source files + {compiled_count} compiled extensions")
    print(f"  {protected_skipped} protected .py files stripped")
    print(f"  Done → {zip_path.name} ({size_mb:.1f} MB)")


def verify_no_protected_sources(zip_path: Path):
    """Fail-safe: assert no protected .py files leaked into the zip."""
    with zipfile.ZipFile(zip_path) as zf:
        names = zf.namelist()
    leaked = [
        n for n in names
        if n.endswith(".py") and any(x in n for x in [
            "handlers/", "licensing/", "kariana_agent_daemon",
            "mcp_server.py", "unreal_socket_server",
            "bedrock_backend", "tool_executor", "tool_schema",
        ])
    ]
    if leaked:
        print(f"SECURITY VIOLATION — protected .py files in {zip_path.name}:")
        for f in leaked:
            print(f"  {f}")
        raise SystemExit(1)
    print(f"  Security check PASSED — no protected .py sources in {zip_path.name}")


def main():
    parser = argparse.ArgumentParser(description="Package KARIANA for distribution")
    parser.add_argument("--artifacts", required=True,
                        help="Directory containing downloaded CI artifacts")
    parser.add_argument("--output", required=True,
                        help="Output directory for release zips")
    parser.add_argument("--platforms", nargs="+", default=["windows"],
                        choices=["windows", "macos", "linux"],
                        help="Platforms to package (default: windows)")
    args = parser.parse_args()

    repo_root = Path(__file__).parent.parent
    artifact_root = Path(args.artifacts)
    output_dir = Path(args.output)
    output_dir.mkdir(parents=True, exist_ok=True)

    for platform_key in args.platforms:
        platform_name, ext, artifact_subdir = PLATFORM_MAP[platform_key]
        artifact_dir = artifact_root / artifact_subdir
        if not artifact_dir.exists():
            print(f"WARNING: No artifacts for {platform_name} at {artifact_dir} — skipping")
            continue
        build_platform_zip(repo_root, artifact_dir, platform_name, ext, output_dir)
        verify_no_protected_sources(output_dir / f"KARIANA-{platform_name}.zip")

    print("\n=== Release packages ===")
    for z in sorted(output_dir.glob("*.zip")):
        print(f"  {z.name}  ({z.stat().st_size / 1024 / 1024:.1f} MB)")


if __name__ == "__main__":
    main()

    Security Properties of This Design#

    Threat How It's Handled
    Client shares plugin with non-client License is client-named and unique — KARIANA can identify who leaked it
    Client forges a license Ed25519: impossible without the private key, which only KARIANA holds
    Client extracts HMAC key from binary No HMAC key. Extracting the embedded public key from the .pyd only gives the verifier half — useless for creating signatures
    Client reverse-engineers methodology Cython-compiled .pyd requires disassembly with IDA/Ghidra — significantly raises the bar for a pre-alpha client
    Private key lost Restore from 1Password. Rotation requires new keypair + reissue all licenses (plan this ahead of time)
    Client changes machines License is NOT hardware-bound — they copy the .lic file to the new machine. No friction.

    Known Risks & Mitigations#

    Risk Impact Mitigation
    UE 5.7 ships a different CPython ABI than standard 3.11 .pyd fails to load inside UE Test loading one .pyd inside UE before first client delivery — if broken, compile inside UE's own Python
    FastMCP decorators behave differently when compiled mcp_server.py tools not registered Smoke test catches import errors; if @mcp.tool() fails, keep mcp_server.py as a thin .py launcher that imports the compiled module
    cryptography library not available in UE's Python licensing/core.py fails to import Installer must run pip install cryptography into UE's embedded Python — verify this in the installer script
    Intel Mac clients (if any) ARM .so won't load Add macos-13 runner to CI matrix for x86 build; ask clients their architecture
    Private key rotation (if key is ever compromised) Must reissue all licenses Generate new keypair, recompile plugin with new public key, reissue all client licenses — plan a comms process for this
