    Your First Commands#

    Let's start using KARIANA with some simple commands.

    Prerequisites#

    Before starting, ensure:

    • Unreal Engine is running with a project open
    • KARIANA plugin is enabled
    • Claude Desktop is configured and connected

    Verify Connection

    Ask Claude: "Can you see my Unreal Engine?" - Claude should confirm the connection.

    Basic Commands#

    Spawning Objects#

    The most basic operation - creating objects in your level:

    "Spawn a cube"

    This creates a cube at the world origin (0, 0, 0).

    With position: 

    "Spawn a sphere at position 500, 200, 100"

    With rotation: 

    "Spawn a cube at 0, 0, 100 rotated 45 degrees on the Z axis"

    With scale: 

    "Spawn a cube scaled to 2, 2, 0.5"

    Available Shapes#

    Shape Command
    Cube "Spawn a cube"
    Sphere "Spawn a sphere"
    Cylinder "Spawn a cylinder"
    Cone "Spawn a cone"
    Plane "Spawn a plane"

    Adding Lights#

    "Add a point light at 0, 0, 300"

    Light types: 

    "Add a spotlight facing down at position 0, 0, 500"
"Add a directional light for sunlight"
"Create a rect light at 200, 0, 200"

    Moving Objects#

    "Move the cube to position 100, 200, 0"
"Move the sphere 500 units along the X axis"
"Rotate the cube 90 degrees on the Y axis"
"Scale the cylinder to 0.5 on all axes"

    Deleting Objects#

    "Delete the cube"
"Delete all spheres in the level"
"Delete the last spawned actor"

    Working with Materials#

    Creating Materials#

    "Create a red material called M_Red"
"Create a blue metallic material"
"Create a material with roughness 0.2 and metallic 1.0"

    Applying Materials#

    "Apply the red material to the cube"
"Make the sphere gold colored"
"Apply M_Red to all cubes in the level"

    Practical Examples#

    Example 1: Simple Scene#

    "Create a simple scene with:
- A floor plane at 0, 0, 0 scaled to 10, 10, 1
- A red cube on top of it
- A point light above the cube"

    Example 2: Material Test#

    "Spawn 5 spheres in a row along the X axis, 200 units apart.
Give each one a different material: red, green, blue, gold, and glass."

    Example 3: Lighting Setup#

    "Set up three-point lighting:
- Key light (bright) at front-right
- Fill light (dimmer) at front-left
- Back light for rim lighting"

    Tips for Better Results#

    Be Specific#

    Good

    "Spawn a cube at position 100, 0, 50 with scale 2, 2, 2"

    Vague

    "Put something somewhere"

    Use Descriptive Language#

    Good

    "Create a warm golden material with high metallic (0.9) and low roughness (0.1)"

    Vague

    "Make it look nice and shiny"

    Reference Objects Clearly#

    Good

    "Move the cube named 'PlayerSpawn' to position 0, 0, 100"

    Ambiguous

    "Move that thing over there"

    Common Issues#

    Problem Solution
    "Can't find actor" Use the exact name or spawn a new one
    Objects spawn at origin Specify the position explicitly
    Wrong object selected Be more specific with names
    Material doesn't apply Ensure the actor has a mesh component
