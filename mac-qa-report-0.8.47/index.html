    Mac-Specific Fixes (v0.8.47)#

    1. Stdin O_NONBLOCK — Daemon crash loop fix#

    • File: Content/Python/kariana_agent_daemon.py, Content/Python/backends/bedrock_daemon_adapter.py
    • Problem: Mac's FMacPlatformProcess::CreatePipe sets O_NONBLOCK on pipe read ends. When dup2'd to daemon stdin, readline() returns empty immediately instead of blocking, causing "stdin EOF" crash loop.
    • Fix: os.set_blocking(sys.stdin.fileno(), True) at daemon startup.

    2. WritePipe off-by-one — False write failure fix#

    • File: Source/UnrealAssistantIntegration/Private/KarianaClaudeCodeBridge.cpp
    • Problem: Mac's FMacPlatformProcess::WritePipe(FString) writes N+1 bytes (data + appended newline) but checks BytesWritten == N, always returning false on success.
    • Fix: Use raw-bytes WritePipe(void*, const uint8*, int32, int32*) overload which doesn't have the bug.

    3. Venv Python discovery — No-shell path resolution#

    • File: Source/UnrealAssistantIntegration/Private/KarianaClaudeCodeBridge.cpp
    • Problem: Shell-based Python discovery broke on paths with spaces ("Unreal Projects").
    • Fix: Direct FPaths::FileExists(.venv/bin/python) check, no shell invocation.

    4. Platform guard — Windows-only include#

    • File: Source/UnrealMCPBridge/Private/PythonBridge.cpp
    • Fix: #if PLATFORM_WINDOWS around Microsoft/MinimalWindowsApi.h include.

    5. wstring → string — Mac filesystem path type#

    • File: Source/UnrealAssistantIntegration/Private/Widgets/SKarianaDropTarget.cpp
    • Fix: Canonical.string() instead of Canonical.wstring() (Mac value_type is char, not wchar_t).

    6. Blueprint variable types — Added object references#

    • File: Source/GenerativeAISupportEditor/Private/MCP/GenBlueprintUtils.cpp
    • Added: material_instance, material, texture, static_mesh, actor to the C++ add_variable type map.

    7. MCP SSE auto-start disabled#

    • File: Content/Python/socket_server_config.json
    • Fix: auto_start_mcp_sse: false — prevents fastmcp/requests import errors in UE's embedded Python (not needed with ECA-style C++ architecture).

    8. JSON chunked Unicode escape handling#

    • File: Content/Python/unreal_socket_server.py
    • Fix: Treat Invalid \uXXXX escape as incomplete data (same as Unterminated string) when receiving chunked socket data.

    Environment Requirements (Mac)#

    1. Python 3.10+ via Homebrew venv: /opt/homebrew/bin/python3.12 -m venv .venv
    2. Venv packages: claude-agent-sdk, fastmcp, mss, Pillow, requests, openai
    3. UE Python package: mss (installed into UE's embedded Python)
    4. Config: Config/DefaultRemoteControl.ini with bEnableRemotePythonExecution=True
    5. Build: Compile from source (no pre-built Mac dylibs)
